# کتابخانه آردوینو TTP223Row توسط : حمیدرضا میلانی نیا [ARDUnia]

یک کتابخانه قدرتمند و غیرمسدودکننده (Non-Blocking) برای آردوینو، طراحی شده جهت پردازش جسچرهای (حرکات) پیچیده از یک ردیف شامل ۲ تا ۵ سنسور لمسی خازنی TTP223.

## مزایای کلیدی
* **بدون وابستگی (Zero Dependencies):** کاملاً مستقل. تنها به هسته استاندارد `Arduino.h` متکی است و نیازی به نصب هیچ کتابخانه جانبی دیگری ندارید.
* **سبک و سریع:** با استفاده از معماری ماشین حالت (State-machine) و اشغال کمترین میزان حافظه بهینه‌سازی شده است، که آن را برای میکروکنترلرهای با منابع محدود ایده‌آل می‌کند.
* **سازگاری بالا (کراس‌پلتفرم):** روی انواع بردهای سازگار با آردوینو از جمله بردهای AVR (مانند Uno، Mega، Nano)، ESP8266، ESP32 و سایر میکروکنترلرها بدون هیچ مشکلی کار می‌کند.
* **نصب و استفاده آسان (Plug & Play):** به راحتی به پروژه‌های شما اضافه می‌شود بدون اینکه دغدغه مدیریت کتابخانه‌های پیش‌نیاز را داشته باشید.

## ویژگی‌ها
* **پشتیبانی از چند سنسور:** پیکربندی آسان برای ۲ تا ۵ سنسور در یک ردیف.
* **معماری غیرمسدودکننده:** استفاده از `millis()` برای زمان‌بندی، که باعث می‌شود حلقه اصلی برنامه (loop) شما بدون وقفه اجرا شود.
* **تشخیص ضربه (Tap):** شناسایی تک‌ضرب و چندضرب (مثلاً 2TS, 3TS).
* **تشخیص چند انگشتی:** شناسایی لمس و ضربه همزمان با چند انگشت (مثلاً 2T2F, 3T3F).
* **جسچرهای کشیدنی (Swipe):** تشخیص کشیدن دست از چپ به راست (L2R)، راست به چپ (R2L) و حرکت رفت و برگشتی (RLLR).
* **تشخیص لمس طولانی:** شناسایی لمس طولانی با یک یا چند انگشت همزمان (مثلاً LT1F, LT2F).

## آموزش نصب
۱. این مخزن (Repository) را به صورت فایل `.zip` دانلود کنید.
۲. نرم‌افزار Arduino IDE را باز کنید.
۳. از منوی بالا به مسیر **Sketch** -> **Include Library** -> **Add .ZIP Library...** بروید.
۴. فایل `.zip` دانلود شده را انتخاب کنید.

## راه‌اندازی سریع

```cpp
#include "TTP223Row.h"

// راه‌اندازی 4 سنسور متصل به پین‌های 2، 3، 4 و 5
TTP223Row mySensors(4, 2, 3, 4, 5); 

void setup() {
  Serial.begin(115200);
  mySensors.begin();
}

void loop() {
  String gesture = mySensors.HowTouch();
  
  if (gesture != "") {
    Serial.print("Gesture: ");
    Serial.println(gesture);
  }
}


خروجی‌های پشتیبانی‌شده

    1TS1, 1TS2: لمس کوتاه تکی روی سنسور ۱، ۲ و غیره.

    2TS1, 3TS2: دو ضرب یا سه ضرب روی یک سنسور مشخص.

    1T2F, 2T3F: تک ضرب همزمان با ۲ انگشت، دو ضرب با ۳ انگشت و غیره.

    L2R: کشیدن دست از چپ به راست.

    R2L: کشیدن دست از راست به چپ.

    RLLR: کشیدن دست به صورت رفت و برگشتی.

    LT1F_1, LT2F: لمس طولانی با ۱ انگشت (روی یک سنسور مشخص) یا با ۲ انگشت همزمان.
