# Contributing to TTP223Row

Thank you for helping improve the library.

1. Create a branch from `main`.
2. Keep the public API backward compatible unless the change is explicitly planned for a major release.
3. Add or update a host-side regression test for every gesture-engine change.
4. Compile all examples for at least Arduino Uno before opening a pull request.
5. Describe hardware, sensor count, timing values, expected output, and actual output when reporting a gesture bug.

Pull requests must pass the host tests and example-compilation matrix before merge.
